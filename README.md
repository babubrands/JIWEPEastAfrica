# JIWEP East Africa Company Limited

Static portfolio website for JIWEP East Africa Company Limited, built from the provided company portfolio PDF.

## Files

- `index.html` - website content and structure
- `styles.css` - responsive styling
- `script.js` - mobile navigation and header behavior
- `assets/images/` - extracted portfolio visuals
- `JIWEP EAST AFRICA COMPANY PORTOFOLIO 2.pdf` - downloadable company portfolio

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server.
